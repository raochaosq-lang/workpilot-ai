# CloudBase 账号与同步验收手册

这份文档用于验证声流 Senlo 的真实账号链路：注册、登录、退出、刷新保持、本地数据导入云端，以及基础跨设备同步。

## 打开开发者配置

本地启动后访问：

```text
http://localhost:8001/?devCloud=1
```

只有本地调试地址带 `?devCloud=1` 时，顶部才会出现“开发者配置”。普通用户入口不展示 CloudBase、环境 ID、地域、客户端 key 或数据库集合说明。

## 腾讯云控制台需要确认

1. 已创建腾讯云开发 CloudBase 环境。
2. 身份认证已开启邮箱/密码登录。
3. Web 安全域名包含当前地址，例如 `http://localhost:8001`。
4. 已创建 7 个集合：`profiles`、`interviews`、`history_records`、`transcripts`、`ai_summaries`、`uploaded_files`、`user_settings`。
5. 数据库安全规则限制登录用户只能读写自己的 `user_id` 数据。
6. 前端只填写环境 ID、地域和 Web 安全客户端 key。不要把 SecretId / SecretKey 填进前端。

## 测试 CloudBase 初始化

1. 点击“开发者配置”。
2. 填入 CloudBase 环境 ID、地域和 Web 安全客户端 key。
3. 点击“测试初始化”。

预期：

- 通过：显示 CloudBase 初始化成功，并展示环境和地域。
- 失败：检查 SDK 是否可访问、环境 ID 是否正确、客户端 key 是否正确。

## 测试 Auth

点击“测试 Auth”。

预期：

- 未登录时，应显示“未登录或仅检测到匿名身份，当前仍为本地模式”。
- 已真实登录时，应显示真实邮箱或账号 ID。
- 不应出现 `User ID: anon`。

## 测试邮箱密码能力

点击“测试邮箱登录能力”。

预期：

- 能检测到登录方法和注册方法。
- 如果提示未检测到，去 CloudBase 控制台确认邮箱/密码登录是否开启。

## 测试数据库权限

1. 先真实登录账号。
2. 回到“开发者配置”。
3. 点击“测试数据库权限”。

预期：

- 每个集合读取当前用户数据成功。
- `user_settings` 测试写入成功，并能清理测试记录。
- 如果提示权限不足，检查集合安全规则里的 `user_id` 限制。

## 测试注册

1. 点击右上角“登录 / 注册”。
2. 切换到“立即注册”。
3. 输入合法邮箱、至少 8 位密码和确认密码。
4. 点击“注册”。

预期：

- 如果 CloudBase 要求邮箱验证，页面提示“注册成功，请前往邮箱完成验证后再登录”。
- 如果注册后直接登录，顶部切换为“云端模式”并显示用户邮箱。
- 失败时不应出现 `[object Object]`，应展示可读错误。

## 测试登录

1. 使用已注册并完成验证的邮箱登录。
2. 登录成功后确认弹窗关闭。
3. 顶部显示“云端模式”和当前邮箱。
4. 账号菜单显示真实 User ID，不是 `anon`。
5. 刷新页面，状态仍保持云端模式。

## 测试退出

1. 点击账号菜单。
2. 点击“退出”。

预期：

- 顶部回到“本地模式”和“登录 / 注册”。
- 不显示云端同步、User ID 或上次同步时间。
- 本地面试记录不被删除。

## 测试刷新后保持登录

1. 登录账号。
2. 刷新 `http://localhost:8001/?devCloud=1`。
3. 再切换到 AI 复盘页。

预期：

- 面试管理页和 AI 复盘页顶部账号状态一致。
- 不出现一边云端模式、一边本地模式。

## 测试本地数据同步到云端

1. 未登录状态下新增一条面试记录。
2. 登录账号。
3. 如果弹出“检测到本地数据”，点击“同步到云端”。
4. 刷新页面，确认记录仍在。
5. 退出后再登录同一账号，确认云端能拉回这条记录。
6. 如有条件，在另一个浏览器或无痕窗口登录同一账号，确认能看到同一条记录。

## 常见错误

- Web 安全域名未配置：登录或数据库请求被拒绝。把 `http://localhost:8001` 加入 CloudBase Web 安全域名。
- 邮箱密码登录未开启：登录提示邮箱 provider 不存在。去身份认证里开启邮箱/密码登录。
- 邮箱未验证：先打开验证邮件，再回到应用登录。
- 数据库集合不存在：创建缺失集合，集合名必须和本文一致。
- 数据库权限不足：检查安全规则，确保当前登录用户能读写 `user_id` 等于自己 ID 的记录。
- CloudBase 环境 ID 错误：初始化失败或请求找不到环境，重新复制环境 ID。
- Web 安全客户端 key 错误：Auth 或数据库请求失败，重新生成/复制 Web 安全客户端 key。
- localStorage 旧状态污染：在开发者配置里点击“清理旧账号状态”，不会删除面试记录、转写和复盘历史。
- 网络请求失败：检查网络、代理、VPN、DNS，以及 `static.cloudbase.net` 和 CloudBase API 是否可访问。
