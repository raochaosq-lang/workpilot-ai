# 声流 Senlo

一个静态 HTML 单页应用，用于个人求职面试管理与 AI 面试复盘。核心覆盖面试记录、轮次进度、会议地址、JD、面试备注、纪要转写和复盘报告。

## 面试管理

- 支持新增、编辑、删除个人面试记录，并按公司、岗位、base 地点、联系人、进展和状态筛选。
- 支持 AI 识别导入已有面试表格，优先兼容 `.xlsx`、`.csv`、`.tsv` 和 `.txt`。
- 导入会自动归一化面试公司、岗位、JD、1-4 轮时间、方式/地址、是否通过和备注；未配置模型时会使用本地字段匹配兜底。
- 支持导出本地面试数据 JSON，便于在接入云同步前做备份。

## 本地持久化

- 未登录时采用本地模式：面试记录、历史复盘、上传文件元数据、转写记录和报告快照会保存在当前浏览器本地，换设备不可见。
- 本地模式只适合体验和临时备份，不等同于账号体系或多设备同步。
- API Key 仅用于当前浏览器配置，不要提交到仓库或写入代码。

## 账号与云端同步

项目主云端方案已切换为腾讯云开发 CloudBase：

- 支持邮箱密码注册、登录、登出和刷新后 session 恢复。
- 登录后按 CloudBase 登录用户写入 `user_id`，面试记录、转写、AI 复盘、历史记录和模型非密钥配置会同步到云端。
- 未登录时仍可本地体验；登录后可从账号菜单导入本地匿名数据到当前账号。
- 用户数据隔离必须依赖 CloudBase 数据库安全规则，不要只依赖前端过滤。
- LLM/ASR 的 API Key 仍只保存在当前浏览器，不会明文写入云端。
- 当前版本先同步音频文件 metadata、转写和复盘；音频原文件云存储后续可接 CloudBase Storage。

### 腾讯云开发 CloudBase 初始化

1. 在腾讯云开发 CloudBase 创建 Web 应用环境。
2. 在身份认证里启用邮箱密码登录。
3. 在数据库里创建集合：`profiles`、`interviews`、`history_records`、`transcripts`、`ai_summaries`、`uploaded_files`、`user_settings`。
4. 配置数据库安全规则，确保登录用户只能读写 `user_id` 等于自己的数据。
5. 复制环境 ID、地域和 Web 安全客户端 key。注意这里填写的是环境 ID，不是 `https://...` URL。
6. 当前静态 HTML 无法直接读取 `.env`，正式部署推荐通过 `assets/env.js` 注入这些值；本地调试可把 `SHOW_DEV_CLOUD_CONFIG` 设为 `true` 或访问 `?devCloud=1` 打开隐藏开发者配置。
7. 注册/登录后新增面试记录，再用另一个浏览器登录同一账号验证跨浏览器同步。

普通用户路径只展示“登录 / 注册”和账号菜单，不会出现 CloudBase 环境、集合列表或安全规则配置。开发者配置只用于本地调试，不应在生产入口暴露。

### 云端连接排查

- 如果提示 CloudBase Web SDK 未加载，请检查 `https://static.cloudbase.net` 是否可访问。
- 如果登录失败，请确认 CloudBase 已启用邮箱密码登录、已完成邮箱验证，并且 Web 安全域名包含当前访问域名。
- 如果数据库读取失败，请确认集合已创建，并且数据库安全规则允许登录用户读写自己的 `user_id` 数据。
- 如果测试提示没有邮箱密码方法，请确认 CloudBase Web SDK 可以正常加载，并优先使用最新版 Web SDK。
- 前端只能使用 Web 安全客户端 key，不要把腾讯云 SecretId / SecretKey 放进页面。

Supabase 相关 SQL 文件仍保留在 `supabase/` 目录中，仅作为旧方案备份，不再是当前主路径。

## GitHub Pages

项目入口是 `index.html`，可直接通过 GitHub Pages 从 `main` 分支根目录发布。
